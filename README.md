# DDR Clone

<img src="https://img.shields.io/badge/-Unreal Engine-0E1128?style=flat&logo=unrealengine&logoColor=white"/><img src="https://img.shields.io/badge/-C++-00599C?style=flat&logo=cplusplus&logoColor=white"/>

A rhythm gameplay prototype built with **Unreal Engine 5** and **C++**, featuring audio-synchronized note spawning, real-time input evaluation, scoring systems, and visual feedback mechanics.

Inspired by Dance Dance Revolution, players must synchronize inputs with incoming notes to maintain combos and achieve high scores.

## Technical Highlights

- Developed a real-time rhythm gameplay system using **Unreal Engine 5** and **C++**
- Implemented timing windows for input evaluation (Perfect / Good / Miss)
- Built audio-synchronized note spawning and gameplay timing logic
- Created combo tracking and score progression systems
- Integrated Niagara visual effects and camera feedback for player responsiveness
- Used a hybrid **C++ and Blueprint** workflow for gameplay iteration

## Features

- Precise input timing evaluation
- Music-driven gameplay synchronization
- Combo and scoring feedback systems
- Dynamic visual effects and camera feedback
