# DDR Clone

Inspired by Dance Dance Revolution, built using Unreal Engine and C++.

Players must time their inputs precisely with incoming notes, syncing gameplay with music to build combos and achieve high scores.


I also used this as an opportunity to deepen my understanding of Unreal Engine, combining C++ with Blueprints and Niagara to rapidly prototype while maintaining control over core systems.

This project represents a step toward my goal of becoming a gameplay engineer, building systems that feel as good as they function.

Features
- Real-time input judging system (Perfect / Good / Miss)
- Audio-synced note spawning and timing
- Combo tracking with feedback systems
- Camera shake and visual effects using Niagara
- Hybrid workflow using C++ and Blueprints
